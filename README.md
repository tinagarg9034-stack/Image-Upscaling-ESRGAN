# 🖼️ AI Image Upscaler using Real-ESRGAN

## 📌 Project Overview

This project is an AI-powered Image Upscaler built using Python, Streamlit, and the Real-ESRGAN deep learning model. It enhances low-resolution images and generates high-quality outputs while preserving details.

---

## ✨ Features

- Upload JPG, JPEG and PNG images
- AI-powered image enhancement
- High-quality image upscaling using Real-ESRGAN
- Download enhanced images
- Simple and user-friendly Streamlit interface

---

## 🛠 Technologies Used

- Python
- Streamlit
- PyTorch
- OpenCV
- Real-ESRGAN
- Git & GitHub

---

## 🚀 How to Run

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```
